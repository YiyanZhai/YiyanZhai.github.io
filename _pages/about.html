Clock2Q+

A cache replacement algorithm designed for metadata in VMware vSAN. It distinguishes short bursts of access from reuse over time, helping the cache retain useful blocks and reduce misses with low overhead.

Identifying LLM-Generated Text

We train a language model to identify a text’s source by predicting a label as the next token, without a separate classification layer. We also introduce OpenLLMText, a dataset of about 340,000 human-written and model-generated samples.

VLDB 2026
Industrial track

Clock2Q+: A Simple and Efficient Replacement Algorithm for Metadata Cache in VMware vSAN

Yiyan Zhai, Bintang Dwi Marthen, Sarath Balivada, Vamsi Sudhakar Bojji, Eric Knauft, Jitender Rohilla, Jiaqi Zuo, Quanxing Liu, Maxime Austruy, Wenguang Wang, Juncheng Yang

Read paper ↗
Research summary

Clock2Q+ uses three queues and a correlation window to prevent closely spaced accesses from being mistaken for lasting reuse. On the evaluated metadata traces, it achieves up to a 28.5% lower miss ratio than S3-FIFO. It has low CPU and memory overhead, scales across multiple CPUs, and has been deployed in VMware vSAN and VDFS.

MLSys 2026

FlashInfer-Bench: Building the Virtuous Cycle for AI-driven LLM Systems

Shanli Xing, Yiyan Zhai, Alexander Jiang, Yixin Dong, Yong Wu, Zihao Ye, Charlie Ruan, Yingyi Huang, Yineng Zhang, Liangsheng Yin, Aksara Bayyapu, Luis Ceze, Tianqi Chen

Read paper ↗
Research summary

FlashInfer-Bench brings kernel generation, benchmarking, and deployment into one workflow. Its shared trace format describes kernel definitions, workloads, implementations, and evaluation results. A dataset of real serving traces and a public leaderboard support comparisons across agents, while a kernel substitution mechanism lets inference engines use the best-performing implementations.

WebLLM: A High-Performance In-Browser LLM Inference Engine

Charlie F. Ruan, Yucheng Qin, Akaash R. Parthasarathy, Xun Zhou, Ruihang Lai, Hongyi Jin, Yixin Dong, Bohan Hou, Meng-Shiun Yu, Yiyan Zhai, Sudeep Agarwal, Hangrui Cao, Siyuan Feng, Tianqi Chen

Read paper ↗
Research summary

WebLLM is an open-source JavaScript framework for running LLMs entirely in the browser. It provides an OpenAI-style API, uses WebGPU for GPU acceleration and WebAssembly for CPU computation, and compiles optimized kernels with MLC-LLM and Apache TVM. Local execution lets applications run inference without sending prompts to a server.

EMNLP 2023

Token Prediction as Implicit Classification to Identify LLM-Generated Text

Yutian Chen, Hao Kang, Yiyan Zhai, Liangze Li, Rita Singh, Bhiksha Raj

Read paper ↗
Research summary

This work treats text-source identification as next-token prediction. We fine-tune T5 to predict source labels without adding a classification layer and compare it with classification based on hidden states. We also introduce OpenLLMText, with about 340,000 samples from humans, GPT-3.5, PaLM, LLaMA, and GPT-2.
